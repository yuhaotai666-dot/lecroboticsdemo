# LEC Robotics 网站改版方案

对照竞品 Pudu Robotics 的产品页布局，梳理出 LEC Robotics 现在最该改的地方，并给出一版可执行的改版方案。

注意：现有网站是用 Webflow 搭的，我无法直接改动它。这份方案的产出是一份改版说明 + 在本项目里做一版可点击的参考页面（首页 + 产品总览页 + 产品详情页），你可以拿去照着改 Webflow，或者直接用这版新站。

## 一、现在最严重的问题

**1. 产品页里还留着模板占位内容**
Dinerbot T10 页面上有 5 处 "Lorem ipsum" 假文字、"Short heading here" 假标题和一个写着 "Button" 的按钮；下面的 Case Studies 三个案例全是假文字。价格是真的（£8,247 + VAT，分期 £192/周），也就是说客户看到真实报价的同时，也看到没写完的页面 —— 这非常伤信任。

**2. 大量图片是同一张占位图**
预约页和产品页底部的行业标签卡片，C30 / C40 / T8 / T9 / T10 / UGOT 全部用同一张图；首页的 Xbot Lite 用的还是 Webflow 自带的灰色占位图。另外 UGOT 的描述被错写成 "3-in-1 Intelligent Floor Cleaning"（那是 C30 的文案）。

**3. 没有导航栏**
整站顶部只有 Logo 和一个 "Book a Call"。没有产品、行业方案、资源、关于我们的入口。对比 Pudu：顶部有 Products / Industries / Resources / About，产品下面还按「清洁机器人 / 商用配送 / 工业配送 / 具身智能 / 配件」分类。LEC 有 11 款机器人却没有一个产品总览页，用户只能从首页往下滚着找。

**4. 首页首屏是过期活动**
首页最大的标题是「Robot Week」（9 月 7–18 日切尔西展厅）。活动已经结束，新访客第一眼看到的不是「你们是谁、能帮我解决什么」。

**5. 同一批产品在首页重复出现两次**
C40、C30、Xbot S Pro、T10、W3、T9、S100 在首页出现两遍，文案还不一致，像是没清理干净的两个版本。

**6. 转化路径混乱**
"Book a Call" 页面上的 "Contact Us" 按钮链接指向 `#`（什么都不做）；页面上其它按钮又指向 `/contact-us`。同时存在 Book a Call、Contact Us、Enquire Now、Book a Demo、Learn More 五种说法，指向两三个不同页面。

**7. SEO 基础**
首页标题是「Home | LEC Robotics」，"Home" 白白浪费了最值钱的位置。产品图几乎都没有替代文字。产品页没有产品结构化数据（价格已经公开，很适合做）。

## 二、可以从 Pudu 借鉴的结构

Pudu 的产品体系是「分类 → 型号 → 行业方案」三层，而且每个型号都有一句极短的定位（"Light-payload Industrial Delivery Robot"）、状态标签（NEW / Hot）、统一规格的产品图。LEC 其实已经有很好的一句话定位（"Delivery robot. Digital display. Two jobs at once."），缺的是把它们组织起来的骨架。

建议采用：

```text
首页
 ├─ 产品总览 /products      按用途分类：餐饮配送 / 清洁 / 楼宇配送 / 咖啡冰淇淋 / 工业搬运 / 教育
 │    └─ 产品详情 /products/xxx
 ├─ 行业方案 /solutions     酒店 / 餐饮 / 医疗 / 零售 / 仓储 / 教育（现在只是标签，应该做成页面）
 ├─ 资源 /resources         规格书下载、案例、活动
 └─ 预约 /book-a-call
```

LEC 相对 Pudu 的优势要放大：**公开价格 + 分期方案 + 英国本地部署与合规**。Pudu 全站不报价，LEC 已经报了，这是很强的差异化，应该做成产品总览页上的对比表格（型号 / 载重 / 续航 / 一次性价格 / 周供），而不是藏在各个详情页里。

## 三、改版方案（按优先级）

**第一优先：清理（一两天能做完，收益最大）**
- 删掉所有 Lorem ipsum、"Short heading here"、"Button" 占位内容；写不出来的先隐藏整个板块
- 替换所有重复占位图；补上 Xbot Lite 真实产品图；修正 UGOT 描述文案
- 首页去重，每款机器人只出现一次
- 统一 CTA：主按钮全站统一叫「Book a Demo」，指向同一个页面；修掉指向 `#` 的死链
- 首页首屏换成品牌主张，Robot Week 改成首屏下方一条可随时替换的活动条

**第二优先：结构**
- 加全站导航栏：Products / Solutions / Resources / About / Book a Demo
- 新建产品总览页，按用途分类切换，卡片带一句话定位 + 起始价格
- 产品总览页加一张全型号对比表（载重、续航、速度、价格、周供）
- 六个行业标签做成真正的方案页，每页配对应机型和一个真实案例

**第三优先：内容与转化**
- 补 3 个真实案例（现在是假文字）—— 需要你提供客户名称、场景、成效数据
- 每个产品页放规格书下载（T10 已经有 PDF，其它机型补齐），用邮箱换下载做线索沉淀
- 做一个 ROI 测算器：输入门店人力成本 → 算出回本周期。这是首页上「get the ROI figures」承诺过但没兑现的东西
- 页面标题改成带关键词的写法，产品页加 Product 结构化数据（含价格）

   - 产品总览页（分类切换 + 全型号对比表）
   - 一个产品详情页样板（以 Dinerbot T10 为例，含规格、价格、分期、规格书下载）
